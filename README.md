## 🧩 Website Sections

### 🌤️ Hero Section

A powerful headline, call-to-action buttons and four animated statistics about employer preferences, job readiness, salary difference and freelancer satisfaction.

### ⚠️ The Problem

Six reasons the degree-centered system is failing:

* Outdated syllabus
* Theory-heavy education
* No industry connection
* High cost
* Lack of jobs
* Lost creativity

### 🎯 In-Demand Skills

Eight most wanted skills of 2025:

* Web Development
* AI & Machine Learning
* UI/UX Design
* Digital Marketing
* Cybersecurity
* Mobile App Development
* Video Editing
* Data Analytics

### ⚖️ Degree vs Skill

A direct comparison across time, cost, syllabus, experience, job guarantee, career paths and industry readiness.

### 🌟 Success Stories

Testimonials from a full-stack developer, a brand designer and an agency CEO who succeeded without a traditional degree.

### 🗺️ Roadmap

A six-step, 12-month plan:

1. Choose a skill
2. Learn the foundation
3. Build projects
4. Start freelancing
5. Build a network
6. Scale up

### 📧 Call to Action

An email subscription section offering free resource guides, weekly tips and community access.

## 🚀 How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/mahamuda87-wdd/Skill-over-degree.git
```

### 2. Open the Project

```bash
cd Skill-over-degree
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use **VS Code + Live Server** to run the project locally.
